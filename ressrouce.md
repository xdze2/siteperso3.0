A few options that fit the scrapbook/early-web aesthetic:

GifCities (archive.org/details/gifcities) — the Internet Archive's index of GeoCities GIFs. Animated, 16-color, the real thing. Best for genuine "found on a 1998 homepage" feel.
Pixeland / Cyberpunk Pixel Icon Pack (itch.io) — clean 16×16 / 32×32 pixel icons, often free, modern but pixel-perfect.
Pixelarticons (pixelarticons.com) — open-source, MIT, SVG, monochrome, 5px stroke, ~480 icons. Closest to a "8-bit Feather/Lucide". Probably the most practical for a static site.
Iconic / Pixeleria — small free packs on dafont and OpenGameArt.
Macintosh System 1–6 icons (kreativekorp.com, macintoshgarden) — 1-bit B&W, dithered, very "serious notebook" vibe. Pairs well with your typewriter headers.
Susan Kare's original Mac icon set — same family, hand-drawn 32×32 1-bit. Iconic (literally).
Dingbats / Wingdings / ZapfDingbats as actual fonts — easiest: type a character, get a symbol. No image files.
Unicode symbols (▲ ▼ ★ ☞ ✎ ❧ ✦ ❖ ☙) — zero assets, render in any font, very scrapbook.
